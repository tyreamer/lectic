# Expertise Compiler — Teaser Launch Page

A visually stunning, Apple-level, dark-cinematic teaser launch page for **Expertise Compiler**.

## Visual Direction & Polish
- **Cinematic Palette**: Void black (`#050508`), obsidian slate, with neon cyan (`#00f0ff`), electric violet (`#9d4edd`), and emerald teal (`#00ffb2`) gradient glows.
- **Dynamic Physics Background**: Interactive Canvas particle constellation with node proximity connections and mouse repulsion/attraction.
- **Synthesized Audio Engine**: Zero-dependency Web Audio API synthesizer for futuristic interaction clicks, resonant compile pulses, and harmonic chords.
- **Live Compiler Centerpiece**: Multi-stage visualization demonstrating `Sources -> Collection -> Compiled Expertise (IR) -> Goal -> Result` with 6 interactive outcome routes (`Review`, `Decide`, `Learn`, `Plan`, `Create`, `Do`).
- **Interactive Storytelling**:
  - Split Comparison: *Content Today* vs *Compiled Expertise*
  - 6-Stage System Pipeline: Interactive inspection with JSON schema payloads
  - 6 Universal Use Cases: 3D perspective tilt cards with modal deep-dives
  - Category Matrix: *What Typical AI Tools Do* vs *What Expertise Compiler Does*
  - Interactive Terminal: "What you say" with 6 clickable prompt scenarios + "What the system gives back" (Collection, Method, Result, Reusable Skill)
  - Architectural Vision: 4-tier isometric layer stack
  - Early Access VIP Waitlist: Email submission with use case selector, confetti celebration, and holographic ticket pass saved in `localStorage`.

## Quick Start

### 1. Install Dependencies
```bash
cd website
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
Generates production-ready static assets in `dist/`.

### 4. Preview Production Build
```bash
npm run preview
```
