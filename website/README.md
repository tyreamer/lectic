# Archived design prototype

This React project is retained as a design reference. It is not the maintained public product site, and its older product copy is not a feature specification.

The maintained site is `docs/index.html`, with `docs/registry.html`, shared CSS/JavaScript, a checked catalog and actual starter pack. GitHub Pages serves that directory. Make public copy and onboarding changes there.

The prototype no longer collects email addresses or reports a fictional waitlist signup. Do not deploy it as the Lectic site.
