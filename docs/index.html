The Architectural Difference

Keep useful methods
ready for the next task.

Lectic keeps sources, extracted knowledge, reusable methods, and previous results together. Your assistant supplies the reasoning; the library carries what you have saved across projects.

The Portable Unit

Portable Packs (.lectic)

A file carrying knowledge, methods, and source citations. Signed packs use Ed25519; verify the publisher's fingerprint separately to establish identity. Updates preserve previous knowledge history.

Zero-Daemon Intake

Drop Inbox

Drop web shortcuts, notes, or transcripts into the folder reported by status. No separate folder watcher is needed. Items appear when your connected assistant checks the library or inbox.

Evidence You Can Check

Traceable sources

Check quoted passages, evidence links, and source hashes with lectic verify. Its exit code supports CI checks. Verification establishes traceability, not the truth of a source or interpretation.

Universal Protocol

Connect your assistant

Automatic local setup supports Claude Code and Codex. Other compatible MCP clients need manual configuration. Hosted chat and phones need a running HTTPS connector.

Honest engineering boundaries

Traceable work.
Transparent limits.

Lectic checks that quotes and stored artifacts match their sources. This establishes traceability, not whether a source is true or an interpretation is correct. Your assistant still needs to reason carefully.

Text and transcripts can be processed. Optional YouTube caption retrieval can fail. Other web links are saved without downloading their pages. PDF, image, audio, and video attachments are preserved; built-in OCR and transcription are not available.

New local installations use ~/.lectic. A hosted connector stores knowledge on its host and must keep running. Anyone with its share link can read and change the library. Your assistant's provider may receive material used in a task.

Lectic is an open-source alpha. The catalog contains one real teaching pack. A completed comparative user study has not yet established improved task quality or retention. We welcome feedback from your own work.
