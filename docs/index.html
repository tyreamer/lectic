Honest engineering boundaries

Traceable work.
Transparent limits.

Lectic deterministically checks that quotes and stored artifacts match their sources via content hashes. That establishes strict provenance and traceability—it does not replace human domain judgement.

Text, notes, and transcripts (.txt, .md, .vtt, .srt) are fully processed. YouTube caption retrieval via yt-dlp is optional. Other web links are stored as references. All knowledge remains 100% local on your machine in ~/.lectic.

Lectic is an open-source alpha under active development. We welcome your feedback, PRs, and real-world case studies.
