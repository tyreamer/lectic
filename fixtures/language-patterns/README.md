# Authored language-pattern fixtures

Ari and Blake are fictional. These short transcripts were written to exercise language evidence contracts, not taken from a real person or generated by an extraction model.

Expected observations: Ari uses two distinct "Just to confirm" questions about practical booking details, uses administrative words in the same conversation, and gives direct instructions in a separate urgent announcement. Blake's conspicuous phrase and explicit preference belong to Blake. The urgent example limits any claim that Ari always qualifies requests. Caption times identify locations, not measured delivery or pauses.

The regression test supplies authored interpretation records to the normal workflow and checks independent selection, evidence validation, pack round-trip, and private-brief exclusion. Live extraction and writing quality require the separate acceptance protocol.
